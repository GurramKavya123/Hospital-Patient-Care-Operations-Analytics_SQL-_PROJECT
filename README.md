# Hospital Patient Care Operations Analytics Using MySQL

## Project Overview
Hospital Patient Care Operations Analytics is a SQL-based data analysis project developed using MySQL. The project focuses on analyzing hospital operations, including patient information, appointment demand, treatment performance, doctor workload, and room utilization.

## Objectives
- Analyze patient distribution across different cities.
- Understand patient appointment patterns and booking behavior.
- Evaluate treatment outcomes, waiting times, and treatment duration.
- Analyze doctor performance and workload.
- Examine room utilization and availability.
- Identify operational challenges and support better decision-making.

## Database Tables
This project uses five relational tables:

1. **Patients** – Stores patient details and registration information.
2. **Doctors** – Contains doctor profiles, specialties, and employment details.
3. **Rooms** – Stores room types, equipment, and availability.
4. **Appointments** – Maintains patient appointment and booking details.
5. **Treatments** – Records treatment details, status, duration, and cost.
